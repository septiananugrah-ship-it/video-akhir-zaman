# Menuju Akhir Zaman

Video (2K, 30 FPS, ±21 menit, 26 adegan) tentang alur akhir zaman menurut Al-Qur'an dan hadis sahih — dari khalifah & amanah, para nabi, tanda kecil, tanda besar (Mahdi, Dajjal, Isa, Yakjuj Makjuj, matahari dari barat, sangkakala) — ditutup renungan tentang zaman teknologi dan kecerdasan buatan. Dalil diberi sumber; renungan diberi label jelas. Dibuat dengan [Remotion](https://remotion.dev).

- `npm run dev` — Remotion Studio.
- Render: Actions → **Render Akhir Zaman 2K 30FPS** → Run workflow.
- Sumber: `naskah/AUDIT.md`.
